สร้างข้อมูลตัวอย่าง

Seed ผ่าน Firebase Authentication จริง (Email/Password provider — ต้องเปิดใน Firebase Console ก่อน ดู README) — สร้าง 5 บัญชี user_accounts + 1 บัญชี admin_accounts + คำขอ pickup_requests ที่ผูก user_id เป็น uid จริงของแต่ละบัญชี กดซ้ำได้ (ถ้าบัญชีมีอยู่แล้วจะ sign in เพื่อเอา uid เดิมแทนการสร้างซ้ำ)
หมายเหตุ: ถ้าเคยกด seed จากเวอร์ชันก่อนหน้า (แบบยังไม่มี login) จะมี doc เก่าชื่อ demo-user-1..5 / demo-request-1..5 ค้างอยู่ใน Firestore ซึ่งไม่ผูกกับ uid จริงอีกต่อไป — ปล่อยทิ้งไว้ได้ไม่กระทบอะไร หรือลบเองผ่าน Firebase Console ถ้าต้องการให้ข้อมูลสะอาด
