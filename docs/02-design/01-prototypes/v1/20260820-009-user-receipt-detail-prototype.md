# User — หน้าใบเสร็จ (Receipt Detail) Prototype

## Persona & บริบทการใช้งาน

**User** เข้าดูใบเสร็จหลังคำขอมีสถานะ "เสร็จสิ้น" เพื่อดูหลักฐานการซื้อขาย (ประเภทขยะ, น้ำหนัก, ราคา) ที่สาเล้งกรอกส่งเข้าระบบหลังปิดงาน

## อ้างอิงจาก

- Journey: node V "สาเล้งกดปิดงานและส่งใบเสร็จเข้าระบบ", node W "สถานะ เสร็จสิ้น", node X "User เห็นใบเสร็จ" ใน [[../20260820-001-user-pickup-request-journey|User — สร้างและติดตามคำขอเรียกรถซาเล้ง Journey]]
- Feature: [[../../../01-requirements/feature-list#User|ดูใบเสร็จที่สาเล้งส่งเข้าระบบหลังงานเสร็จสิ้น]]
- Business rule: [[../../../01-requirements/01-spec/20260819-001-saleng-pickup-request|Call-Saleng spec]] — "โครงสร้างใบเสร็จที่สาเล้งส่งหลังปิดงาน ประกอบด้วยรายการ (ประเภทขยะ, น้ำหนัก, ราคาต่อประเภทและ/หรือราคารวม) โดยมีได้หลายรายการต่อ 1 ใบเสร็จ" และ "ค่าธรรมเนียมเรียกใช้งาน (platform fee) 20 บาทต่อคำขอที่ขายขยะสำเร็จ หักออกจากเงินที่ user ได้รับจริง"

> **หมายเหตุการออกแบบ (inferred):** สเปกไม่ได้ระบุตรงๆ ว่าต้องแสดง breakdown ค่าธรรมเนียม 20 บาทให้ user เห็นในหน้าใบเสร็จหรือไม่ แต่เนื่องจากค่าธรรมเนียมนี้หักออกจากเงินที่ user ได้รับจริง (ไม่ใช่หักจากสาเล้ง) จึงเป็นข้อมูลที่ user ควรรู้เพื่อความโปร่งใส — prototype นี้จึงรวม breakdown ค่าธรรมเนียมและยอดสุทธิไว้ในใบเสร็จด้วย หากทีมต้องการซ่อนรายละเอียดนี้จาก user ให้แจ้งกลับเพื่อแก้ไข

## Layout

Header ย้อนกลับ: back chevron + title "ใบเสร็จ" + subtitle "คำขอ #SL-2607" (ไม่มี bottom tab bar)

1. **Summary card** ด้านบน: วันที่ปิดงาน (รูปแบบไทย เช่น "27 ก.ค. 2569"), ชื่อสาเล้งผู้ปิดงาน
2. **List รายการขยะ** (แต่ละแถวคือ 1 รายการในใบเสร็จ ตาม business rule รองรับได้หลายรายการ): ชื่อประเภทขยะ + น้ำหนัก (กก.) ชิดซ้าย, ราคารวมของรายการนั้นชิดขวา — แสดงราคาต่อหน่วยเป็น meta text เล็กใต้ชื่อประเภท (เช่น "10 กก. × 10 บาท/กก.")
3. **เส้นแบ่งบางๆ** `--color-neutral-300` คั่นก่อนส่วนสรุปยอด
4. **Subtotal row**: "รวมมูลค่าขยะ" ชิดซ้าย + ยอดรวมชิดขวา
5. **Fee row**: "ค่าธรรมเนียมบริการ (20 บาท/คำขอ)" ชิดซ้าย + "-20 บาท" ชิดขวา (มีเครื่องหมาย "-" กำกับชัดเจน ไม่ใช้สีอย่างเดียวสื่อความหมายลบ ตาม UX rule ข้อ 2)
6. **Total row** (ตัวหนา ขนาดใหญ่กว่าแถวอื่น): "ยอดที่คุณได้รับ" ชิดซ้าย + ยอดสุทธิชิดขวา (สีเขียว `--color-success-600`)

## Components & Design Tokens ที่ใช้

- Summary card, List row — พื้นหลัง `--color-neutral-card`, radius `--radius-md`
- Typography: รายการทั่วไป Body 16px, total row ใช้ H3 18px Semibold, meta text (ราคาต่อหน่วย) Caption 12–13px `--color-text-secondary`
- เส้นแบ่งบาง `--color-neutral-300` เท่านั้น ไม่ใช้ shadow หนัก ตาม UX rule ข้อ 1

## States (Empty / Loading / Error)

- **Loading**: skeleton แทนที่ summary card และ list รายการระหว่างโหลดข้อมูลใบเสร็จ
- **Error**: โหลดใบเสร็จไม่สำเร็จ → ข้อความ + icon เตือนโทน `--color-danger` พร้อมปุ่ม "ลองใหม่"
- ไม่มี Empty state (หน้านี้เข้าถึงได้ต่อเมื่อคำขอมีสถานะ "เสร็จสิ้น" และมีใบเสร็จแล้วเท่านั้น)

## Interaction Notes

- หน้านี้เป็น read-only ทั้งหมดสำหรับ User ไม่มี action แก้ไข (การกรอกใบเสร็จทำโดยสาเล้งเท่านั้น)
- เข้าถึงหน้านี้ได้จาก 2 ทาง: ปุ่ม "ดูใบเสร็จ" ใน receipt summary card ของหน้าสถานะการเข้ารับ หรือกด card คำขอที่สถานะ "เสร็จสิ้น" ในหน้าติดตาม (ผ่านหน้าสถานะก่อน)
