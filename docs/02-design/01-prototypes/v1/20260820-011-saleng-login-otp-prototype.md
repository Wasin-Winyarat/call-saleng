# Saleng — เข้าสู่ระบบ/สมัครสมาชิก (เบอร์โทร/OTP) Prototype

## Persona & บริบทการใช้งาน

**Saleng** (คนขับรถซาเล้งที่รับซื้อของเก่าตามบ้าน) เปิดเว็บแอปเป็นครั้งแรกเพื่อสมัครสมาชิก หรือกลับมาเข้าสู่ระบบอีกครั้งระหว่างขับรถหาแหล่งงาน หน้านี้เป็นจุดเริ่มต้นก่อนเข้าถึงฟีเจอร์ใดๆ ของฝั่งสาเล้งได้ทั้งหมด ต้องใช้งานง่ายด้วยมือเดียวบนมือถือ เพราะส่วนใหญ่ใช้งานระหว่างอยู่หน้างานหรือระหว่างขับรถ (ไม่ใช้ระหว่างขับจริง แต่ต้องกรอกเร็วในเวลาสั้นๆ)

## อ้างอิงจาก

- Journey: node A "ลงทะเบียน/เข้าสู่ระบบด้วยเบอร์โทร/OTP" ใน [[../20260820-002-saleng-job-fulfillment-journey|Saleng — รับงานและปิดงาน (Job Fulfillment) Journey]]
- Feature: [[../../../01-requirements/feature-list#Saleng|ลงทะเบียน/เข้าสู่ระบบด้วยเบอร์โทร/OTP]] (Must have — inferred)
- Business rule: [[../../../01-requirements/01-spec/20260819-001-saleng-pickup-request|Call-Saleng spec]] — "การยืนยันตัวตนสาเล้งใน MVP ใช้เบอร์โทร/OTP เท่านั้น" ไม่ต้องอัปโหลดเอกสารทะเบียนรถหรือบัตรประชาชน และ "สาเล้งต้องลงทะเบียนและได้รับการอนุมัติจาก Admin ก่อนจึงจะเห็นและรับงานได้"

## Layout

หน้าเต็มจอ ไม่มี header ย้อนกลับ และไม่มี bottom tab bar (อยู่นอก main flow ตาม navigation pattern ข้อ 5 ของ DESIGN.md)

1. **โลโก้แบรนด์** กึ่งกลางด้านบน (ตรา mascot สาเล้ง) + tagline เล็กใต้โลโก้ ("บริการเก็บขยะรีไซเคิล — อนุรักษ์สิ่งแวดล้อม ชุมชนสะอาด") + label เล็กกำกับใต้ tagline ว่า "สำหรับคนขับรถซาเล้ง" เพื่อไม่ให้สับสนกับหน้า login ฝั่ง User
2. **Segmented toggle** 2 ตัวเลือก: "เข้าสู่ระบบ" / "สมัครเป็นสาเล้ง" (ตัวที่ active = พื้นหลัง `--color-primary-600` ตัวอักษรขาว, inactive = ตัวอักษร `--color-text-secondary`)
3. **ขั้นที่ 1 — กรอกเบอร์โทร**: input เบอร์โทรศัพท์ (label + placeholder "08X-XXX-XXXX") ใต้ input มี helper text "เราจะส่งรหัส OTP ไปยังเบอร์นี้"
4. ปุ่ม Primary เต็มความกว้าง "ขอรหัส OTP"
5. **ขั้นที่ 2 — ยืนยัน OTP** (แสดงแทนที่ขั้นที่ 1 หลังกดขอรหัส): ช่องกรอกเลข OTP 6 หลัก (แยกกล่องทีละหลัก), ข้อความนับถอยหลัง "ขอรหัสใหม่ได้ใน 00:60" → เปลี่ยนเป็นลิงก์ "ส่งรหัสอีกครั้ง" สีเขียวเมื่อครบเวลา
6. ปุ่ม Primary เต็มความกว้าง "ยืนยัน"
7. **เฉพาะกรณีสมัครเป็นสาเล้ง + OTP ถูกต้อง**: แสดงฟอร์มเพิ่มเติมต่อท้าย — ช่อง "ชื่อ-นามสกุล" (required), ช่อง "พื้นที่ที่สนใจรับงาน" (dropdown/chip เลือกได้หลายเขต/ตำบลในอำเภอเมือง เชียงราย — ตั้งค่าเริ่มต้นได้ แก้ไขภายหลังได้ที่โปรไฟล์) เบอร์โทรใช้ค่าที่ยืนยันแล้วไม่ต้องกรอกซ้ำ → ปุ่ม Primary "ส่งสมัคร"
8. **ข้อความอธิบายท้ายฟอร์มสมัคร**: "หลังส่งสมัคร บัญชีของคุณจะรอการตรวจสอบจาก Admin ก่อนจึงจะเริ่มรับงานได้" — เตรียมผู้ใช้ก่อนเจอหน้ารออนุมัติ

## Components & Design Tokens ที่ใช้

- ปุ่ม Primary เต็มความกว้าง — พื้นหลัง `--color-primary-600`, radius `--radius-lg`, ตัวอักษรสีขาว, ความสูง ≥44px ตาม UX rule ข้อ 3 (persona มีผู้สูงอายุร่วมด้วย)
- Segmented toggle — พื้นหลังรวม `--color-neutral-card`, active pill `--color-primary-600`
- Input field / Choice chip (พื้นที่ที่สนใจ) — border `--color-neutral-300`, radius `--radius-md` / `--radius-full`, focus/selected border-fill `--color-primary-600`
- Typography: H1 24px Bold สำหรับหัวข้อ, Body 16px สำหรับ label, Caption 12–13px `--color-text-secondary` สำหรับ helper text/countdown/ข้อความอธิบายท้ายฟอร์ม
- Error text ใต้ input ใช้สี `--color-danger` (`#D97757`) พร้อม icon เตือนกำกับเสมอ (ไม่ใช้สีอย่างเดียว ตาม UX rule ข้อ 2)

## States (Empty / Loading / Error)

- **Loading**: ปุ่ม "ขอรหัส OTP" / "ยืนยัน" / "ส่งสมัคร" เปลี่ยนเป็น spinner + disable ปุ่มระหว่างรอ response
- **Error — เบอร์โทรไม่ถูกต้อง**: ข้อความ "กรุณากรอกเบอร์โทรให้ถูกต้อง" สี `--color-danger` ใต้ input พร้อม icon เตือน
- **Error — OTP ผิด/หมดอายุ**: ข้อความ "รหัส OTP ไม่ถูกต้องหรือหมดอายุ กรุณาลองใหม่" ใต้ช่องกรอก OTP, เคลียร์ช่องกรอกอัตโนมัติ
- **Error — เบอร์นี้เคยสมัครแล้ว** (กดสมัครด้วยเบอร์ที่มีบัญชีสาเล้งอยู่แล้ว): แสดง inline message พร้อมลิงก์สลับไปแท็บ "เข้าสู่ระบบ" ให้ทันที
- ไม่มี Empty state สำหรับหน้านี้

## Interaction Notes

- ปุ่ม "ขอรหัส OTP" ถูก disable 60 วินาทีหลังกดเพื่อป้องกันการขอรหัสซ้ำถี่เกินไป
- เมื่อกรอกครบ 6 หลักในช่อง OTP ระบบ auto-submit โดยไม่ต้องกดปุ่ม "ยืนยัน" เพิ่ม (ปุ่มยังคงแสดงไว้เป็นทางเลือกสำรอง)
- **เข้าสู่ระบบสำเร็จ**: ถ้าบัญชีผ่านการอนุมัติจาก Admin แล้ว → นำทางไปหน้ารายการคำขอที่เปิดอยู่ (หน้าแรกของสาเล้ง) / ถ้ายังไม่ผ่านการอนุมัติ → นำทางไปหน้ารอ Admin อนุมัติบัญชี
- **สมัครสำเร็จ** (ส่งฟอร์มสมัครครบ) → นำทางไปหน้ารอ Admin อนุมัติบัญชีเสมอ (บัญชีใหม่ยังไม่เคยผ่านการอนุมัติ)
- Toggle ระหว่าง "เข้าสู่ระบบ" กับ "สมัครเป็นสาเล้ง" จะรีเซ็ตฟอร์มกลับไปขั้นที่ 1 เสมอ
